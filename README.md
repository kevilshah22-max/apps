# Gnu Launchpad

Gnu Launchpad is the first internal product for the Gnu product studio: a command centre for taking product ideas from research through launch.

## MVP
- Opportunity pipeline
- Searchable ideas
- Opportunity scoring
- Research → Product → Build → Launch workflow
- Responsive web UI

## Run
npm install
npm run dev
