05 / Local AI video rendering

Turn your storyboard into an MP4

Generate a storyboard directly above using local Ollama, or create one manually. Export the project JSON and run the local render agent with ComfyUI and FFmpeg. Optional local Piper narration is supported.

  1. Generate a full-script storyboard in the Local AI Script Studio above, or build one manually, then export project JSON.
  2. Install and start ComfyUI with an image-generation model and save an API-format workflow.
  3. Follow the CartoonForge Render Agent setup guide.
  4. Run the agent to assemble a 1080p MP4. Use --require-video with a video-diffusion workflow to reject image-only output.

The agent runs locally; no paid API is required. A GPU is recommended. Compatible video workflows can generate full-motion clips; image-only workflows use camera-motion keyframes. Character consistency depends on the chosen model. Lip-sync is not included.

CartoonForge combines a browser storyboard editor, optional local script-to-storyboard generation and a local AI render pipeline. Output quality depends on the model, workflow and hardware you install. Check model and voice licences before publishing generated work.
