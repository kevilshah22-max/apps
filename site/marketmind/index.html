Import OHLCV candles from a CSV file exported by a source you trust. MarketMind computes transparent technical summaries and scenario levels locally, then shows which specialist modules are planned. It does not connect to a broker or issue guaranteed signals.

01 / Market data intake

Expected columns: timestamp, open, high, low, close, volume. Column names are case-insensitive; date/time and OHLCV aliases are supported. Use one instrument and one timeframe per file.

No data loaded. Source, exchange, timezone, timeframe and freshness must be verified by you. Demo data is synthetic and must never be treated as a real market.
